---
description: 주간 회고 작성
argument-hint: "[메모]"
---

이번 주 회고를 작성한다. 사용자 메모: $ARGUMENTS

1. 이번 ISO 주에 바뀐 파일을 확인한다 (`git log --since` 또는 수정일). 새로 생긴 논문 노트, 실험 노트, open-questions 변경 사항을 모은다.
2. `notes/templates/weekly.md` 형식으로 `notes/roadmap/weekly/<YYYY-Www>.md`를 작성한다. "한 것"과 "읽은 것"은 실제 바뀐 파일을 근거로 채우고 링크를 건다.
3. 지난주 회고의 "다음 주" 체크리스트와 비교해서 완료·미완료를 표시한다.
4. `notes/roadmap/index.md`의 현재 Phase 체크포인트와 비교해서 진행 상황(앞섬·맞음·뒤처짐)을 한 줄로 평가하고, 다음 주 할 일을 3~5개 제안한다.
5. `notes/roadmap/index.md`의 "주간 회고" 목록에 링크를 추가한다.
6. 사용자에게 막힌 점이나 느낀 점을 한두 개 물어보고, 답을 받으면 "막힌 것 / 배운 것"에 반영한다.
