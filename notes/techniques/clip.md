> 사진과 설명 문장을 같은 공간에 붙여 놓는 '그림-글자 짝짓기' 학습으로, 나중에 새 물체 이름만으로도 이미지를 알아보는 모델.

**대표 논문**: Learning Transferable Visual Models From Natural Language Supervision (2021) · **분류**: 표현학습

## 해결한 문제
예전에는 이미지를 분류하려면 ImageNet(수백만 장의 사진에 라벨을 붙인 대표 데이터셋)처럼 미리 정한 라벨로 학습해야 해서, 새로운 물체나 문장이 나오면 다시 학습하거나 라벨을 추가해야 했다. 라벨이 적거나 특정 분야에 치우치면 일반화가 약했고, '빨간 컵'처럼 자유로운 표현으로 검색하는 zero-shot(새 라벨로 다시 학습하지 않고 바로 분류)이 어려웠다.

## 핵심 아이디어
마치 사진과 캡션을 맞춰주는 카드 게임처럼, 맞는 짝은 가깝게 틀린 짝은 멀게 만든다. 먼저 이미지 인코더(사진을 숫자 벡터로 바꾸는 네트워크)와 텍스트 인코더(문장을 숫자 벡터로 바꾸는 네트워크)를 함께 학습한다. 학습할 때 사진과 그 사진의 설명 문장을 같은 배치(batch, 한 번에 학습하는 샘플 묶음)에서 비교해, 서로 맞는 쌍의 점수를 높이고 다른 쌍의 점수를 낮춘다. 추론할 때는 'a photo of a {class}' 같은 문장을 텍스트 인코더로 바꾸고, 이미지 벡터와 가장 가까운 문장 벡터를 골라 분류한다.

## 왜 작동하나
웹에서 모은 사진-캡션 쌍은 라벨보다 훨씬 다양하고 크기가 커서, 모델이 수많은 시각 개념을 자연스럽게 배우게 된다. 대조 학습(contrastive learning, 맞는 짝은 당기고 틀린 짝은 밀어내는 학습)은 같은 배치 안의 다른 샘플을 손쉽게 부정 예시로 써서 효율적으로 표현을 정렬한다. 텍스트를 임베딩(숫자 벡터로 만든 표현) 공간에 넣으면 새 클래스도 문장만 바꾸어 바로 시도할 수 있다.

## 트레이드오프
- 프롬프트 문장 하나 바꾸면 결과가 흔들릴 수 있어, 문장 템플릿을 잘 골라야 한다.
- 세밀한 차이, 드문 물체, 복잡한 관계는 놓치거나 편향된 웹 데이터의 영향을 받을 수 있다.
- 학습 데이터와 모델 크기가 커서 계산 비용이 크고, 이미지 생성이나 정밀한 3D 이해 같은 기능은 직접 제공하지 않는다.

## 계보
**이전**
- Supervised image classification on ImageNet(사진에 라벨을 붙여 분류하는 전통 학습)
- Word2Vec / GloVe(단어를 숫자 벡터로 바꾸는 언어 표현 학습)
- SimCLR / MoCo(이미지끼리 비교하는 자기지도 학습)
- Image-text retrieval models(사진과 문장을 서로 찾는 검색 모델)

**이후**
- ALIGN(더 큰 웹 데이터로 CLIP을 확장한 모델)
- OpenCLIP(CLIP을 공개 재현·확장한 생태계)
- BLIP(이미지-언어 이해와 생성을 함께 강화한 모델)
- DALL-E(텍스트로 이미지를 생성하는 모델)
- Stable Diffusion text conditioning(디퓨전(노이즈에서 이미지를 생성하는 모델)에 CLIP 같은 텍스트 조건을 넣는 방식)
- [[techniques/siglip|SigLIP(대조 학습을 더 효율적으로 바꾼 CLIP 변형)]]

## 피지컬 AI에서의 쓰임
- 로봇이 '빨간 컵 집어' 같은 자연어 목표를 이해할 때, 카메라 이미지와 문장 벡터를 비교해 물체를 찾는다.
- VLA(Vision-Language-Action, 보고 말하고 행동하는 로봇 모델)에서 언어 조건을 시각 특징과 연결하는 기본 인코더로 쓰인다.
- 개방형 물체 검출/분할(사전 라벨에 없는 물체도 찾아내는 CV 작업)에서 '고양이', '열린 창문'처럼 사전에 라벨로 배우지 않은 개념도 검색하는 데 쓰인다.

## 💡 아이디어 훅
- 로봇이 실패한 동작을 '실패한 grasp' 같은 문장으로 CLIP에 물어보고 보상 신호로 쓸 수 있을까?
- CLIP의 이미지-텍스트 정렬을 3D 스캔-설명 문장에도 적용하면 로봇이 물체를 더 잘 이해할까?
- 텍스트 프롬프트 대신 로봇의 과거 행동 로그를 '문장'처럼 인코딩하면 더 안정적인 목표 표현이 될까?
