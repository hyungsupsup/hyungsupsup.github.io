> 시뮬레이터를 일부러 마구잡이로 흔들어 놓고 학습시켜서, 진짜 세상이 와도 '또 하나의 변형판'처럼 느껴지게 만드는 sim-to-real(시뮬레이션→실제 전이) 요령

**대표 논문**: Domain Randomization for Transferring Deep Neural Networks from Simulation to the Real World (2017) · **분류**: 로봇 특화

## 해결한 문제
로봇을 실제로 학습시키려면 수만 번 넘어뜨리고 부딪혀야 하는데, 진짜 로봇은 비싸고 느리고 망가지기 쉬워서 그게 불가능에 가깝다. 그래서 시뮬레이터에서 학습하는데, 시뮬레이터의 조명·색·마찰·무게 같은 게 실제와 미묘하게 달라서 학습한 정책이 실물 앞에서 성능이 뚝 떨어졌다. 이 'reality gap(시뮬레이션과 현실의 차이)'을 메우는 게 최대 난제였다.

## 핵심 아이디어
비유하자면, 한 가지 조명 아래서만 얼굴을 외운 사람에게 수백 가지 조명·각도·화장으로 사진을 보여주며 '이게 다 같은 사람이야'라고 가르치는 것과 같다. 실제 작동은 이렇다: (1) 시뮬레이터에서 매 에피소드마다 조명 밝기·물체 색·텍스처·카메라 위치·마찰계수·질량 같은 파라미터를 무작위로 흔든다. (2) 그렇게 매번 다른 '세상'에서 정책이 목표를 달성하도록 학습시킨다. (3) 그러면 정책은 특정 외형에 의존하지 않고 '본질적인 단서'만 보는 법을 익히게 되고, 실제 환경은 그 무작위 분포 안의 한 표본일 뿐이라 자연스럽게 전이된다.

## 왜 작동하나
정책이 특정 조명이나 색깔 같은 '지름길 단서'에 과도하게 맞춰지는 과적합을 막아주기 때문이다. 무작위 변형을 많이 겪으면 모델은 어떤 환경에서도 통하는 강건한 특징만 남기게 되고, 실제 환경의 차이는 학습 때 이미 봤던 변동 범위 안에 들어와 버린다. 즉 '현실을 정확히 흉내내는 것'을 포기하고 '현실을 포함하는 넓은 분포를 학습'하는 쪽으로 문제를 바꾼 발상의 전환이다.

## 트레이드오프
- 무작위 범위를 너무 넓게 잡으면 정책이 지나치게 보수적이고 느릿하게 학습돼 성능이 떨어진다.
- 범위를 너무 좁게 잡으면 실제 환경에서 다시 실패하므로, 무엇을 얼마나 흔들지 정하는 게 사람 손에 달린 어려운 튜닝이다.
- 무작위화가 물리 파라미터까지 들어가면 학습이 불안정해지고 수렴에 훨씬 많은 시뮬레이션 시간이 든다.

## 계보
**이전**
- System Identification(실제 로봇 파라미터를 측정해 시뮬레이터를 정밀하게 맞추는 방식)
- Domain Adaptation(실제 데이터로 시뮬레이션 특징을 보정하는 방식)

**이후**
- Automatic Domain Randomization (ADR)
- Curriculum-based Domain Randomization
- Real2Sim2Real / Digital Twin 보정
- Domain Randomization + Vision-Language-Action 사전학습

## 피지컬 AI에서의 쓰임
- 로봇 손(dexterous hand)으로 물체를 돌리고 쥐는 정책을 시뮬레이터에서 무작위 물체·마찰로 학습시켜 실물 로봇에 그대로 이식
- VLA(로봇이 언어 지시를 보고 행동하는 모델) 학습 시 카메라 위치·조명·배경을 무작위화해 실제 작업장 조명 변화에 강하게 만들기
- 보행 로봇이 울퉁불퉁한 지면·미끄러운 바닥을 시뮬레이션에서 무작위로 겪게 해 실제 야외에서 넘어지지 않게 하기

## 💡 아이디어 훅

- LLM 에이전트 학습에서 '도구 응답 형식'을 무작위화하면 실제 API 환경 적응력이 올라갈까?
- 월드모델(world model)을 학습할 때 물리 파라미터를 무작위화하면 실제 로봇에서의 예측 오차가 줄어들까?
