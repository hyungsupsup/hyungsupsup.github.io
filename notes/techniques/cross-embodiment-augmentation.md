> 여러 로봇의 경험을 한 로봇의 학습 데이터에 보태는 '로봇판 전학생 노트 빌려쓰기' — 팔 길이·센서·행동 공간이 달라도 공통점을 뽑아 학습을 도와주는 기법.

**대표 논문**: 대표 사례: Open X-Embodiment: Robotic Learning Datasets and RT-X Models (2023, 확인 필요) · **분류**: 로봇 특화

## 해결한 문제
로봇마다 팔 길이, 카메라 위치, 손가락 수, 행동 공간이 달라서 한 로봇에서 모은 시범 데이터만으로는 정책이 쉽게 과적합되고 새 상황에 약해진다. 그렇다고 모든 로봇마다 처음부터 대량의 시범을 모으는 것은 너무 비싸고 느리다. 그래서 다른 로봇들이 이미 쌓은 경험을 어떻게든 활용하고 싶었다.

## 핵심 아이디어
비유하면 한 반 학생이 자기 노트만 보지 않고 옆 반 친구들의 노트도 참고해 시험을 준비하는 것이다. 먼저 여러 로봇의 시범 데이터를 모으고, 카메라 이미지·관절값·행동을 공통 형식이나 로봇별 어댑터로 맞춘다. 다음으로 '어떤 로봇인지'를 알려주는 표시(embodiment ID)나 로봇별 모듈을 붙여 하나의 정책을 학습한다. 이때 목표 로봇 데이터에 다른 로봇 데이터를 추가 증강처럼 섞어, 공통된 시각·물리 직관을 배우게 한다.

## 왜 작동하나
다른 로봇의 데이터는 물체를 잡는 법, 밀기, 열기 같은 다양한 장면과 행동 패턴을 보여 주므로 목표 로봇 데이터만 볼 때보다 시각적·물리적 사전지식이 풍부해진다. 로봇별 차이는 공통 표현과 로봇 표시로 흡수되므로, 여러 로봇 데이터가 단순한 잡음이 아니라 정규화 역할을 한다. 결과적으로 적은 목표 로봇 데이터로도 일반화와 견고성이 좋아질 수 있다.

## 트레이드오프
- 로봇마다 행동 공간과 센서가 너무 다르면 데이터를 억지로 맞추다가 오히려 목표 로봇 성능이 떨어지는 negative transfer(전이 방해)가 생길 수 있다.
- 다른 로봇 데이터를 많이 섞을수록 학습과 저장 비용이 커지고, 어떤 데이터를 얼마나 섞을지 고르는 일이 까다롭다.
- 공통 표현이 로봇별 세부 특성을 지워 버리면 정밀 조작처럼 미세한 차이가 중요한 작업에서 손해를 볼 수 있다.

## 계보
**이전**
- [[techniques/behavior-cloning|단일 로봇 behavior cloning(시범 따라하기)]]
- multi-task learning(여러 작업을 한 모델로 배우기)
- [[techniques/domain-randomization|domain randomization(환경을 무작위로 바꿔 적응력 높이기)]]

**이후**
- RT-X/Open X-Embodiment 계열 generalist robot policy
- embodiment-agnostic VLA(로봇 행동까지 출력하는 비전-언어-행동 모델)
- cross-embodiment world model(여러 로봇 경험으로 환경 예측 모델 학습)

## 피지컬 AI에서의 쓰임
- Open X-Embodiment처럼 여러 로봇의 조작 데이터를 모아 하나의 범용 조작 정책을 사전학습할 때 쓴다.
- 목표 로봇 데이터가 적을 때 다른 로봇·인간 시연 데이터를 섞어 fine-tuning(추가 학습)해 적응 속도를 높인다.
- VLA 모델을 여러 로봇 데이터로 먼저 학습시킨 뒤 새 로봇에 붙여, 새 로봇용 데이터 수집 부담을 줄이는 데 활용한다.

## 💡 아이디어 훅
- 로봇별 행동 공간을 억지로 하나로 맞추는 대신, '로봇별 번역기'를 두고 공통 잠재 행동 공간을 배우면 어떨까?
- 다른 로봇 데이터를 무조건 섞지 말고, 목표 로봇과 비슷한 로봇 데이터를 골라 증강하는 데이터 선택 규칙을 만들 수 있을까?
- cross-embodiment augmentation을 월드모델에 적용해, 여러 로봇의 경험으로 '행동하면 환경이 어떻게 변하는가'를 더 일반적으로 예측하게 할 수 있을까?
