> Graph Neural Network(GNN)은 그래프(점과 선으로 된 관계망)에서 각 점이 이웃의 정보를 모아 자기 상태를 업데이트하는 신경망이다.

**대표 논문**: Semi-Supervised Classification with Graph Convolutional Networks (2017) · **분류**: 아키텍처 모듈

## 해결한 문제
기존 신경망은 이미지처럼 격자 구조나 고정된 벡터 입력에 강했지만, 사람·사물·단어처럼 관계가 복잡하고 이웃 수가 제각각인 데이터는 다루기 어려웠다. 그래서 관계 정보를 손으로 만든 특징으로 넣거나, 그래프를 억지로 벡터로 바꿔야 했다.

## 핵심 아이디어
비유하자면 회의실에서 각자가 옆자리 사람 말을 듣고 자기 생각을 바꾸는 과정이다. 먼저 노드(점)마다 특징을 주고, 엣지(선)로 연결된 이웃의 정보를 모은다. 그다음 자기 정보와 합쳐 노드 상태를 업데이트하고, 이 과정을 여러 층 반복하면 멀리 떨어진 관계까지 반영된다. 마지막에는 노드별 예측이나 그래프 전체 요약이 나온다.

## 왜 작동하나
이웃을 직접 연결해 정보를 전달하므로 관계 구조를 학습에 그대로 살릴 수 있다. 노드 수가 바뀌거나 연결이 달라져도 같은 규칙을 적용할 수 있어 그래프 크기에 유연하다. 여러 층을 쌓으면 1-hop(직접 연결)에서 2-hop(이웃의 이웃)으로 영향 범위가 넓어진다.

## 트레이드오프
- 층을 너무 깊게 쌓으면 모든 노드가 비슷한 정보를 갖게 되어 구분이 흐려지는 oversmoothing(과도한 평활화)이 생길 수 있다.
- 그래프가 매우 크면 이웃 정보를 모으는 계산과 메모리가 크게 늘어난다.
- 엣지가 잘못 연결되거나 노이즈가 많으면 잘못된 관계가 예측에 그대로 퍼질 수 있다.

## 계보
**이전**
- Multi-Layer Perceptron(MLP, 입력을 여러 층으로 변환하는 기본 신경망)
- Convolutional Neural Network(CNN, 이미지처럼 격자 데이터를 처리하는 신경망)
- Graph kernels(그래프를 비교하는 전통적 방법)
- DeepWalk / node2vec(그래프에서 노드를 벡터로 만드는 방법)

**이후**
- Graph Attention Network(GAT, 이웃마다 중요도를 다르게 주는 GNN)
- GraphSAGE(새로 들어온 노드도 빠르게 처리하는 GNN)
- Graph Transformer(그래프에 attention(가중치로 중요한 부분을 찾는 방식)을 적용한 모델)
- Graph Neural ODE(그래프 정보 전달을 연속 시간으로 보는 모델)

## 피지컬 AI에서의 쓰임
- 로봇이 방 안의 사물을 노드로, '위/옆/잡기 가능' 같은 관계를 엣지로 만든 scene graph(장면 그래프)를 읽고 다음 행동을 예측한다.
- 멀티 로봇이나 자율주행 차량이 서로의 위치·의도를 그래프로 공유해 충돌 회피나 협업을 결정한다.
- LLM 에이전트가 문서·개체·행동을 지식 그래프로 연결해, 필요한 관계만 따라가며 답이나 계획을 만든다.

## 💡 아이디어 훅
- 로봇 월드모델에서 사물·장면·행동을 그래프로 만들고, GNN으로 '이 물체를 밀면 저 물체가 어떻게 움직일까?'를 예측할 수 있을까?
- LLM의 KV cache(이전에 읽은 단어들의 핵심 정보를 다시 계산하지 않도록 저장해 두는 메모리)를 그래프로 보고, 어떤 토큰끼리 연결을 강하게 유지할지 학습할 수 있을까?
- 이미지·포인트 클라우드를 고정 격자 대신 점과 선으로 표현하면, 로봇이 불규칙한 환경에서도 더 잘 일반화할 수 있을까?
