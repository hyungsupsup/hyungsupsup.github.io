> 미리 학습된 모델에 '작업별 변화량'을 더하거나 빼서 능력을 조합하는, 모델 가중치용 레고 블록 놀이.

**대표 논문**: Editing Models with Task Arithmetic (2023) · **분류**: 효율화·적응

## 해결한 문제
여러 능력을 가진 모델을 만들려면 보통 데이터를 섞어 처음부터 다시 학습하거나, 여러 파인튜닝 모델을 하나로 합치는 복잡한 과정이 필요했다. 이렇게 하면 계산비가 크고, 특정 능력만 추가하거나 제거하기도 어려웠다.

## 핵심 아이디어
비유하자면, 기본 모델은 '평범한 요리사'이고 각 작업은 '레시피 변화 카드'다. 먼저 기본 모델과 특정 작업으로 파인튜닝한 모델의 가중치 차이를 task vector(작업 벡터, 모델이 그 작업을 위해 얼마나 변했는지를 나타내는 변화량)로 계산한다. 이후 새 모델은 기본 모델 가중치에 여러 task vector를 더하거나 빼고, 필요하면 각 변화량에 가중치를 곱해 조합한다. 이렇게 하면 한 모델의 능력만 추가하거나, 원치 않는 행동을 빼는 편집도 가능하다.

## 왜 작동하나
큰 모델에서는 여러 작업을 학습한 변화가 가중치 공간에서 서로 겹치지 않는 방향에 가까운 경우가 많아, 변화량을 더해도 각 능력이 어느 정도 보존된다. 덕분에 데이터를 다시 섞어 학습하지 않고도 여러 능력을 빠르게 합칠 수 있다.

## 트레이드오프
- 기본 모델과 파인튜닝 모델이 같은 구조·같은 초기화에서 나왔어야 하고, 너무 다른 모델끼리는 변화량을 바로 더하기 어렵다.
- 작업이 겹치거나 방향이 충돌하면 성능이 떨어질 수 있어, 더하는 비율을 실험으로 맞춰야 한다.
- 변화량이 선형으로 잘 분리되지 않는 복잡한 능력이나 안전·지식 편집에는 한계가 있을 수 있다.

## 계보
**이전**
- Fine-tuning(미리 학습된 모델을 특정 작업에 맞게 다시 학습)
- Model soups(여러 파인튜닝 모델의 가중치를 평균내 성능을 높이는 방법)
- Multi-task learning(여러 작업을 한 모델에 동시에 학습)
- Weight averaging(가중치를 평균해 모델을 합치는 기법)

**이후**
- TIES-Merging(모델 합칠 때 충돌하는 가중치 방향을 정리하는 방법)
- DARE(가중치 변화량을 드롭아웃하고 스케일링해 더 잘 합치는 방법)
- LoraHub(LoRA(모델의 모든 가중치를 다시 쓰지 않고 작은 어댑터만 추가하는 효율적 파인튜닝) 어댑터를 조합해 새 작업에 빠르게 적응)
- AdaMerging(입력 분포에 따라 모델 합치는 가중치를 자동으로 조절)

## 피지컬 AI에서의 쓰임
- 로봇 조작 정책 모델에 '물체 잡기' task vector를 더하고 '미끄러운 물체' task vector를 빼서 특정 상황만 제거하는 능력 편집.
- VLA(비전-언어-행동, 즉 카메라·명령·로봇 동작을 함께 다루는 모델)에 여러 로봇 작업의 변화량을 조합해, 한 번에 여러 스킬을 가진 정책으로 빠르게 확장.
- Diffusion policy(로봇 행동을 노이즈 제거처럼 생성하는 확산 모델 기반 정책)에서 특정 물체나 환경의 변화량만 추가해, 전체 재학습 없이 새 작업에 적응.
