> 작은 모델이 빠르게 '초안'을 여러 개 던지고, 큰 모델이 그걸 한 번에 채점해서 맞는 것만 채택하는 방식으로 LLM 추론을 2~3배 빠르게 만드는 기법 — 빠른 조수가 받아쓰고 선생님이 검토하는 회의록과 비슷하다.

**대표 논문**: Fast Inference from Transformers via Speculative Decoding (2023) / Accelerating Large Language Model Decoding with Speculative Sampling (2023) · **분류**: 효율화·적응

## 해결한 문제
LLM은 단어를 하나씩 순서대로 생성하기 때문에, 아무리 GPU가 커도 매 스텝마다 큰 모델을 통째로 한 번씩 돌려야 해서 속도가 느리고 GPU가 놀게 된다. 그렇다고 작은 모델로 바꾸면 답변 품질이 떨어지고, 큰 모델을 그대로 쓰면 지연 시간이 길어 대화형 서비스에서 체감이 나쁘다.

## 핵심 아이디어
큰 모델을 '검토자', 작은 모델을 '빠른 조수'로 쓰는 구조다. (1) 작은 draft model(초안 모델)이 다음 단어를 여러 개(예: 4~8개) 연달아 빠르게 뽑는다. (2) 큰 target model(원래 쓰려던 모델)이 그 초안 전체를 한 번의 forward pass로 병렬 채점해서, 각 위치에서 자기 확률분포와 비교한다. (3) 앞에서부터 초안이 '그럴듯한지' 확률적으로 판정해 연속으로 통과한 부분까지만 채택하고, 처음 어긋난 지점에서는 큰 모델이 직접 단어를 하나 뽑아 마무리한다. (4) 이렇게 하면 큰 모델을 한 번 돌릴 때 여러 단어가 확정되어 스텝 수가 줄어든다.

## 왜 작동하나
큰 모델의 병목은 '계산량'이 아니라 '순차적 스텝 수'인데, 초안 검증은 여러 위치를 한 번에 처리하는 병렬 연산이라 거의 공짜에 가깝다. 그리고 채택/기각 규칙을 확률적으로 설계해 두면, 최종적으로 뽑히는 단어의 분포가 큰 모델 단독으로 뽑은 것과 수학적으로 동일해진다(품질 손실 없음). 즉 '느린 큰 모델의 호출 횟수'만 줄이고 결과 분포는 그대로 유지하는 셈이다.

## 트레이드오프
- 초안 모델을 따로 준비·서빙해야 해서 메모리와 시스템 복잡도가 늘어난다.
- 초안이 자주 틀리면(도메인이 안 맞으면) 오히려 손해라서, 태스크에 맞는 draft를 골라야 한다.
- 배치 크기가 크거나 GPU가 이미 꽉 차 있는 상황에서는 이득이 줄어들 수 있다.

## 계보
**이전**
- Autoregressive decoding (표준 순차 생성)
- Draft-then-verify / early-exit 계열 추론 가속
- [[techniques/knowledge-distillation|Knowledge distillation (작은 모델을 미리 만들어 두는 발상)]]

**이후**
- Medusa (여러 개의 예측 헤드로 초안 생성)
- EAGLE / EAGLE-2 (특징 레벨에서 초안 생성)
- Lookahead Decoding
- Self-speculative decoding (별도 draft 없이 레이어 일부를 건너뛰어 초안 생성)

## 피지컬 AI에서의 쓰임
- VLA(로봇 조작 정책)에서 큰 액션 헤드 대신 작은 헤드로 액션 청크 초안을 뽑고 큰 모델이 검증해 실시간 제어 주기를 맞춘다.
- 월드모델·비디오 예측에서 다음 프레임/토큰 초안을 빠르게 생성해 시뮬레이션 루프를 가속한다.
- LLM 기반 로봇 플래너에서 대화형 응답 지연을 줄여 사람-로봇 상호작용의 반응성을 확보한다.

## 💡 아이디어 훅
- 초안 모델을 로봇의 '직관(빠른 정책)'으로, 큰 모델을 '숙고(느린 정책)'로 두는 이중 시스템에 그대로 적용할 수 있지 않을까?
- 초안을 언어 토큰이 아니라 연속 액션(모터 명령)에 적용하면 diffusion policy에도 같은 검증-채택 구조를 쓸 수 있지 않을까?
- 초안 모델이 '언제 틀릴지'를 스스로 예측하게 만들어, 확신이 낮을 때만 큰 모델을 부르는 적응형 라우팅으로 확장할 수 있지 않을까?
