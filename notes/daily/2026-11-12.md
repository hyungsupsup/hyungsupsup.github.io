## 📄 오늘의 논문
### [Is Your Robot's Memory Just a Clock? Temporal Shortcuts in Memory-Augmented VLA Policies](https://arxiv.org/abs/2611.14488v1)
*VLA의 memory가 시간 스탬프에 의존해 '기다림'과 '작업'을 구분하지 못한다는 것을 null event 실험으로 보여주는, memory 설계의 암묵적 가정을 깨는 논문.*

Memory-augmented VLA 정책들이 episode 전반에서 frame을 균일 샘플링하고 시간 스텝을 stamping하는 방식으로 memory를 채운다는 점을 지적한다. RoboMME counting task에서 로봇을 잠깐 멈추거나 wrist를 흔드는 null event를 삽입하면, task와 무관한 변화에도 정책 성능이 흔들린다는 것을 보인다. 즉 시간이 흐르는 것과 사건이 발생하는 것을 구분하지 못하는 temporal shortcut이 존재함을 실증한다.

관련 기법: [[techniques/scaled-dot-product-attention|Scaled Dot-Product Attention]], [[techniques/kv-cache|KV Cache]], [[techniques/action-chunking|Action Chunking]], [[techniques/world-model|World Model (Dreamer)]]

### [One Trajectory, Two Requirements: Accuracy and Local Stability in Euler Sampling for Flow Matching Policies](https://arxiv.org/abs/2611.13311v1)
*Flow matching policy의 Euler step 수를 offline accuracy sweep으로 고정하는 관행에 의문을 제기하고, local Jacobian stability 관점에서 재해석한 분석 논문.*

Flow matching 로봇 정책은 보통 offline accuracy sweep으로 고른 고정 Euler step 수를 inference에 사용한다. 그러나 각 입력(관측, 상태, 언어)과 source noise 조합은 서로 다른 ODE 궤적과 local Jacobian 시퀀스를 정의하므로, nominal 궤적을 잘 따라가는 step 수가 contracting 방향에서는 너무 coarse할 수 있음을 보인다. 두 좌표계 예제를 통해 accuracy와 local stability라는 두 요구가 하나의 step 수로 동시에 만족되기 어렵다는 것을 정식화한다.

관련 기법: [[techniques/flow-matching|Flow Matching]], [[techniques/rectified-flow|Rectified Flow]], [[techniques/ddim|DDIM]], [[techniques/diffusion-policy|Diffusion Policy]]


## 📈 흐름
VLA/world action model이 주류가 되면서 '더 큰 모델'보다 memory·sampling·latent interface 같은 내부 설계의 암묵적 가정을 검증하는 분석 논문이 늘고 있다. 동시에 flow matching/diffusion policy의 inference-time 효율과 안정성을 다루는 실용 연구가 결합되는 흐름이 뚜렷하다.

## 💡 오늘의 질문
**Scaled Dot-Product Attention의 query-key 유사도가 '시간 경과'가 아닌 '사건 발생(event)'에만 반응하도록 event-gated attention을 설계하면, memory-augmented VLA에서 null event에 강건한 memory를 얻을 수 있는가?**

현재 VLA memory는 frame을 시간 스탬프로 stamping해 attention이 시간 축 shortcut을 학습할 여지가 크지만, event-gated attention의 구체적 설계와 long-horizon counting에서의 이득은 검증되지 않았다. 첫 실험은 RoboMME counting task에서 pause/fidget null event를 삽입하고, standard attention vs event-gated attention(KV cache에 event token만 append)의 정확도와 attention map의 시간 축 분포를 비교하는 것이다.
